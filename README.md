# Dunebuddy

IA companheira para Dune: Awakening.  
Detecta eventos como tempestade e falta d'água por OCR e alerta o jogador com voz e mensagens.

## Como usar

1. Instale dependências:
```
pip install -r requirements.txt
```

2. Rode com debug ativado:
```
python main.py --modo-debug
```

## Requisitos adicionais

- Tesseract OCR instalado no sistema (adicione ao PATH)
- Jogo em modo janela (para capturar corretamente)

## Créditos

Companheiro digital desenvolvido para auxiliar no Deep Desert.
